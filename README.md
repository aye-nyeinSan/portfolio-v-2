# My Professional Portfolio v2

A high-performance, mobile/desktop responsive portfolio application built with a modern full-stack approach. This project focuses on efficient state management, utility-first styling, and optimized rendering.

## 🚀 Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Data Fetching:** [TanStack Query v5](https://tanstack.com/query/latest)
* **Backend API:** [ResumeAPI for Visitor Checking](https://github.com/aye-nyeinSan/resume_api)
* **Deployment:** [Vercel]

## ✨ Key Features

* **Server-Side Rendering (SSR) & Static Site Generation (SSG):** Leverages Next.js for optimal SEO and lightning-fast load times.
* **Efficient Data Fetching:** Implements TanStack Query for caching, background updates, and seamless loading states.
* **Responsive Design:** Fully fluid UI built with Tailwind CSS, supporting dark mode and mobile-first layouts.

## 🛠️ Architecture

The application follows a modular architecture to separate concerns between UI components and data logic:

* **/components:** Reusable UI atoms and molecules.
* **/src/app/api:** Logic for external API calls.
* **/app:** Next.js App Router directory for routing and layouts.
